# 콘텐츠 편집 근거

콘텐츠 확인일: 2026-10-28. 디자인 개편일: 2026-10-28. 기존 노션과 사용자가 추가로 제공한 KB HomeDeal 및 DoLog 역량 기술서를 근거로 작성했습니다. 수치와 테스트 결과는 사용자 제공 기록이며 이번 사이트 편집 과정에서 백엔드 테스트를 다시 실행한 것은 아닙니다. 노션 원본은 수정하지 않았습니다.

## 구성

- 첫 화면: 이름, 직무, 짧은 소개, 기존 노션 프로필 사진, 연락처, 주력 기술·서비스 운영·인턴 경험 요약.
- 페이지 순서: 소개 → 기술 스택 → 경험·교육 → 프로젝트. 왼쪽 메뉴, 대형 성과 숫자, 마지막 연락 유도 문구는 제거했습니다.
- 주요 프로젝트: DoLog → KB HomeDeal → 부스끼리. 운영 중인 DoLog를 먼저 두고, 데이터 정합성과 대용량 조회 및 캐시 성능 검증을 보여주는 HomeDeal로 치즈네컷을 교체했습니다. 치즈네컷은 포트폴리오 사이트에서만 제외했으며 노션 기록은 유지했습니다.
- 추가 프로젝트: FedHybrid와 Voisk도 같은 카드 형태로 펼쳐 표시했습니다. 모든 프로젝트의 첫 설명은 수행 내용을 요약하는 한 문장으로 맞췄습니다. DoLog와 HomeDeal은 기술 판단 및 검증 내용을 중심으로 정리했습니다. Voisk의 본인 역할은 프론트엔드로 명시했습니다.
- 경험과 교육은 종료 월 기준 최신순(KB 교육, 멋쟁이사자처럼, IBK 인턴)이며 기간이 없는 학력은 마지막에 두었습니다. 문장과 제목에서 중간점을 제거하고 접속어와 쉼표를 사용했습니다.
- 기업은행 인턴은 디지털 직무·기간만 표기했습니다. 원문에 없는 업무·개발 성과는 추가하지 않았습니다.
- 기술 숙련도 퍼센트, 추상적 성격 표현, 활동 전체 나열, 장식 이미지는 제외했습니다.

## 표현의 한계

- DoLog N+1 개선 전후의 쿼리 수·응답 시간과 WebP 변환 전후 용량은 원문에 수치가 없어 추가하지 않았습니다. 측정값을 확보하면 가장 먼저 보강할 항목입니다.
- DoLog 추가 자료의 누적 조회 1,500회는 이전 수치로 취급했습니다. 사용자의 이번 명시적 지시에 따라 소개에는 '6개월간 누적 조회 6,500+회'와 '약 900명의 활성 사용자'를 적용하고 운영 중으로 표현했습니다.
- DoLog는 전시 단위 비관적 잠금의 선택 이유, 동일 전시의 DELETE와 PATCH 잠금 통일, MySQL 8.4 Testcontainers 동시 제외 테스트 경로별 10회 검증을 추가했습니다. 모든 실제 테스트 결과는 사용자 제공 설명에 근거합니다.
- HomeDeal의 약 600만 건은 플랫폼이 다루는 원본 데이터 규모입니다. 캐시 부하 테스트는 요약 테이블이 이미 적용된 로컬 축소 데이터셋의 동일 지역 반복 조회에 한정했습니다. k6 10→20→30 VU, 4분, ON/OFF 각 3회의 중앙값 기준 p95 7.84→1.59ms와 8.25→1.72ms, 총 42,798건과 오류율 0%를 사용했습니다. 운영 규모 부하나 최대 처리량 결과로 표현하지 않았습니다.
- 첨부의 Grafana 표와 마지막 문장은 개선율 및 측정 구간이 서로 달라 일관된 비교 근거를 확인할 수 없으므로 사이트에 포함하지 않았습니다.
- HomeDeal 자연키 구성 항목 수는 추가 자료에 '15개 자연키'로 적혀 있으나, 구체적인 열 구성의 모호함을 피하기 위해 SHA-256 생성 컬럼과 DB 제약의 동작을 중심으로 표현했습니다.
- FedHybrid의 ‘정확도 약 10% 개선’은 원문에 상대 개선율인지 %p인지 구분되지 않아 사이트의 수치 표현에서 제외했습니다. 70~85% 통신 비용 절감은 프로젝트 실험 조건에 한정했습니다.
- Voisk 비교 수치는 VoiceOver로 특정 메뉴를 주문하는 실험 결과이며, 모든 주문의 보편적인 성능으로 표현하지 않았습니다. 출원은 등록 특허와 구분했습니다.
- ‘운영 중’, 사용자·조회 수치, 출원 상태는 노션 기재 기준입니다. 지원 전 최신 상태와 집계 시점을 확인하는 것이 좋습니다.
- 치즈네컷 관련 수상 연도·프로젝트 기간은 노션 내에서 일부 어긋나 보이는 항목이 있어 수상 목록을 전부 재현하지 않았습니다.
- 자동 노션 동기화, 별도 방문자 추적, 이메일 전송 서버는 포함하지 않았습니다. 메일 링크는 사용자의 기본 메일 앱을 엽니다.
