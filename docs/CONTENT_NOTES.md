## 구성

- 첫 화면: 이름, 직무, 짧은 소개, 기존 노션 프로필 사진, 연락처, 주력 기술·서비스 운영·인턴 경험 요약.
- 페이지 순서: 소개 → 기술 스택 → 경험·교육 → 프로젝트. 왼쪽 메뉴, 대형 성과 숫자, 마지막 연락 유도 문구는 제거했습니다.
- 주요 프로젝트: DoLog → 치즈네컷 → 부스끼리. 본인의 백엔드 기여가 분명한 세 프로젝트를 우선 배치했습니다.
- 추가 프로젝트: FedHybrid와 Voisk도 같은 카드 형태로 펼쳐 표시했습니다. 모든 프로젝트는 설명 한 문단, 담당 내용 3~5개, 역할, 링크, 기술 태그로 구성했습니다. Voisk의 본인 역할은 프론트엔드로 명시했습니다.
- 기업은행 인턴은 디지털 직무·기간만 표기했습니다. 원문에 없는 업무·개발 성과는 추가하지 않았습니다.
- 기술 숙련도 퍼센트, 추상적 성격 표현, 활동 전체 나열, 장식 이미지는 제외했습니다.

## 표현의 한계

- DoLog N+1 개선 전후의 쿼리 수·응답 시간과 WebP 변환 전후 용량은 원문에 수치가 없어 추가하지 않았습니다. 측정값을 확보하면 가장 먼저 보강할 항목입니다.
- FedHybrid의 ‘정확도 약 10% 개선’은 원문에 상대 개선율인지 %p인지 구분되지 않아 사이트의 수치 표현에서 제외했습니다. 70~85% 통신 비용 절감은 프로젝트 실험 조건에 한정했습니다.
- Voisk 비교 수치는 VoiceOver로 특정 메뉴를 주문하는 실험 결과이며, 모든 주문의 보편적인 성능으로 표현하지 않았습니다. 출원은 등록 특허와 구분했습니다.
- ‘운영 중’, 사용자·조회 수치, 출원 상태는 노션 기재 기준입니다. 지원 전 최신 상태와 집계 시점을 확인하는 것이 좋습니다.
- 치즈네컷 관련 수상 연도·프로젝트 기간은 노션 내에서 일부 어긋나 보이는 항목이 있어 수상 목록을 전부 재현하지 않았습니다.
- 자동 노션 동기화, 별도 방문자 추적, 이메일 전송 서버는 포함하지 않았습니다. 메일 링크는 사용자의 기본 메일 앱을 엽니다.
