# 콘텐츠 편집 근거

콘텐츠 확인일: 2026-10-29. 디자인 개편일: 2026-10-28. 기존 노션, 사용자가 추가로 제공한 KB HomeDeal 및 DoLog 역량 기술서, IBK 인턴 활동 설명과 보고서를 근거로 작성했습니다. 수치와 테스트 결과는 사용자 제공 기록이며 이번 사이트 편집 과정에서 백엔드 테스트를 다시 실행한 것은 아닙니다. 노션 원본은 수정하지 않았습니다.

## 구성

- 첫 화면: 이름, 직무, 짧은 소개(DoLog 운영과 축제 부스 및 공연 정보를 제공해 2,500명 이상의 정보 탐색을 도운 교내 축제 서비스 개발 참여 경험), 기존 노션 프로필 사진, 연락처, 주력 기술과 서비스 운영, 학력 요약. 서비스 운영 요약은 '졸업전시 플랫폼 DoLog'로 짧게 표시하며, DoLog 이름과 화살표만 파란색으로 표시해 전시 목록(https://dolog.kr/exhibitions)으로 연결합니다. 동국대학교 컴퓨터공학전공 위 소제목은 사용자 요청에 따라 '학력'으로 표시합니다. 사진은 원본 비율을 유지합니다.
- 페이지 순서: 소개 → 기술 스택 → 교육과 활동 → 수상 내역 → 인턴 경험 → 프로젝트. 왼쪽 메뉴, 대형 성과 숫자, 마지막 연락 유도 문구는 제거했습니다.
- 주요 프로젝트: DoLog → KB HomeDeal → 부스끼리. 운영 중인 DoLog를 먼저 두고, 데이터 정합성과 대용량 조회 및 캐시 성능 검증을 보여주는 HomeDeal로 치즈네컷을 교체했습니다. 치즈네컷은 포트폴리오 사이트에서만 제외했으며 노션 기록은 유지했습니다.
- 추가 프로젝트: FedHybrid와 Voisk도 같은 카드 형태로 펼쳐 표시했습니다. 모든 프로젝트의 첫 설명은 수행 내용을 요약하는 한 문장으로 맞췄습니다. 프로젝트 이름과 기간, 담당 역할 및 기여도는 설명 카드 바깥 위쪽에 배치하고, 카드 안에는 요약 설명과 최대 5개 항목, 링크, 기술을 표시합니다. DoLog와 HomeDeal의 세부 구현 및 반복 설명을 줄여 문제, 해결 방법, 결과를 중심으로 정리했습니다. Voisk의 본인 역할은 프론트엔드로 명시했습니다.
- 교육과 활동은 종료 월 기준 최신순(KB 교육, AWS Cloud Clubs, 멋쟁이사자처럼, IBK기업은행 인턴, Farm System, CJ UNIT)입니다. 인턴은 다른 항목과 동일하게 큰 제목 'IBK기업은행 32기 청년인턴'과 아래 작은 설명 '기업개선부 / 디지털 직무'으로 표시하며, 수행 내용은 기존 인턴 경험 섹션에 유지했습니다. CJ UNIT 활동 기간은 최신 사용자 확인에 따라 2023.08 — 2024.01로 정정했습니다. AWS 활동은 백엔드, 클라우드, 인프라로 요약했습니다. 사용자 지시에 따라 Farm System은 '동국대학교 SW동아리 Farm System 1기 / 웹 개발 트랙'으로 표시하고, CJ UNIT은 활동과 수상 모두 'SW창의캠프 대학생 봉사단 CJ UNIT 9기'로 통일했습니다. 학력은 상단 학력 카드에만 두고, 인턴 수행 내용은 프로젝트 바로 앞의 별도 섹션에 두었습니다. 문장과 제목에서 중간점을 제거하고 접속어와 쉼표를 사용했습니다.
- 수상 내역은 최신순 4건입니다. 최신 사용자 요청으로 멋쟁이사자처럼 어흥콘 최우수상은 제외했습니다. 치즈네컷 프로젝트는 목록에서 제외하되 FARM 우수상은 유지했습니다. FARM 경진대회 수상 시점은 사용자가 2024년 1월로 직접 확인했습니다.
- 기업은행 인턴은 내부 업무시스템 운영과 문서 디지털화 지원, 서비스 기획 및 사용자 조사로 요약했습니다. 특정 금융 지식보다 다른 산업에도 통하는 경험을 중심으로 표현했습니다. 구현하지 않은 LLM 서비스나 인프라를 개발했다고 표현하지 않았습니다.
- Language에 C와 JavaScript를 추가하고 Data & Storage의 Caffeine을 Oracle로 교체했습니다. HomeDeal에서 실제 사용한 Caffeine은 프로젝트 기술로 유지했습니다.
- 기존 프로젝트의 노션 상세 링크 4개를 페이지 내 중앙 팝업으로 교체하고, KB HomeDeal에도 상세 기록을 추가했습니다. 최신 요청에 따라 짧은 요약에서 서비스 소개, 구현 과정, 문제 해결과 결과를 읽는 상세 기록으로 확장했습니다. 팝업 폭을 860px까지 넓히고 내부 스크롤과 고정된 닫기 버튼을 유지했습니다. 모든 프로젝트의 도입 제목은 '서비스 소개'로 통일했습니다.
- `assets/projects/`에는 노션 원본 PNG 5개(DoLog 2개, 부스끼리 2개, FedHybrid 1개)와 HomeDeal 발표자료에서 렌더링한 지도 탐색 및 시세 분석 슬라이드 1개를 저장했습니다. 사용자 요청으로 Voisk 이미지 3개와 표시 코드를 제거했습니다. FedHybrid는 겹치는 소개 이미지 중 두 번째 개선 방향 이미지만 남기고, 서비스 소개 바로 아래에 배치했습니다. 화면은 자르거나 늘이지 않고 원본 비율로 표시하며, 담당 역할을 프론트엔드로 확대해 표현하지 않았습니다. 만료되는 다운로드 주소는 소스에 포함하지 않았고 원본 노션은 수정하지 않았습니다.
- DoLog의 '운영 중' 배지 글씨는 사용자 요청에 따라 10px에서 11px로 소폭 키웠습니다. 서비스 링크는 `https://dolog.kr/exhibitions`로 연결하며 카드 안 GitHub 링크 왼쪽에 두고, 같은 글자 크기와 링크 모양에 글자 굵기만 조금 높였습니다. 상세 기록도 GitHub 링크처럼 테두리와 여백 없이 같은 글자 크기와 오른쪽 화살표로 표시합니다. 배포 브랜치와 페이지 하단 소스 링크는 사용자 요청에 따라 `jiwoo-portfolio`로 변경했습니다.
- FedHybrid의 세부 압축 용어는 최신 요청에 따라 2026-10-29에 노션 원문을 다시 확인해 '변화가 큰 업데이트만 선별하고 압축해 전송'으로 정리했습니다. 원문의 '모델 업데이트 압축' 항목에 '변화가 큰 중요 값만 선별'이 명시되어 있습니다. '가중치가 높은 결과'는 기관별 집계 가중치 또는 모델 가중치의 크기와 혼동될 수 있어 사용하지 않았습니다. 수상 문구는 '이를 통해 ... 수상했습니다.'로 명확히 했습니다. 70~85% 절감은 프로젝트 실험 범위로 유지했고, 정의가 불명확한 정확도 개선 수치는 추가하지 않았습니다.
- 기술 숙련도 퍼센트, 추상적 성격 표현, 활동 전체 나열, 장식 이미지는 제외했습니다.

## 표현의 한계

- DoLog N+1 개선 전후의 쿼리 수·응답 시간과 WebP 변환 전후 용량은 원문에 수치가 없어 추가하지 않았습니다. 측정값을 확보하면 가장 먼저 보강할 항목입니다.
- DoLog 추가 자료의 누적 조회 1,500회는 이전 수치로 취급했습니다. 사용자의 이번 명시적 지시에 따라 소개에는 '6개월간 누적 조회 6,500+회'와 '약 900명의 활성 사용자'를 적용하고 운영 중으로 표현했습니다.
- DoLog는 전시 단위 비관적 잠금과 동시 요청 검증을 요약했습니다. 테스트 도구의 버전과 반복 횟수, 검색 기능에서 같은 조회를 재사용했다는 반복 설명은 사용자 요청으로 본문에서 제외했습니다. 실제 검증 결과는 사용자 제공 설명에 근거합니다.
- HomeDeal의 약 600만 건은 플랫폼이 다루는 원본 데이터 규모입니다. 캐시 부하 테스트는 요약 테이블이 이미 적용된 로컬 축소 데이터셋의 동일 지역 반복 조회에 한정했습니다. k6 10→20→30 VU, 4분, ON/OFF 각 3회의 중앙값 기준 p95 7.84→1.59ms와 8.25→1.72ms, 총 42,798건과 오류율 0%를 사용했습니다. 운영 규모 부하나 최대 처리량 결과로 표현하지 않았습니다.
- 첨부의 Grafana 표와 마지막 문장은 개선율 및 측정 구간이 서로 달라 일관된 비교 근거를 확인할 수 없으므로 사이트에 포함하지 않았습니다.
- HomeDeal 자연키 구성 항목 수는 추가 자료에 '15개 자연키'로 적혀 있으나, 구체적인 열 구성의 모호함을 피하기 위해 SHA-256 생성 컬럼과 DB 제약의 동작을 중심으로 표현했습니다.
- FedHybrid의 ‘정확도 약 10% 개선’은 원문에 상대 개선율인지 %p인지 구분되지 않아 사이트의 수치 표현에서 제외했습니다. 70~85% 통신 비용 절감은 프로젝트 실험 조건에 한정했습니다.
- HomeDeal의 강조는 'Caffeine 캐시'와 '세금과 대출 기준'에만 두고 뒤의 동작 설명은 보통 굵기로 표시합니다. FedHybrid 본문은 '변화가 큰 업데이트'만 강조합니다. Voisk는 최신 요청에 따라 '시각장애인의 독립적인 주문' 대신 연결어를 포함한 'NFC 접속과 단계별 주문 흐름' 전체를 강조합니다.
- HomeDeal의 캐시 구현은 같은 조회 결과를 잠시 보관해 반복 DB 조회를 줄였다는 내용으로 정리했습니다. 최신 사용자 요청에 따라 본문의 약 79% 개선율과 긴 측정 조건 문장은 제외하고 'Caffeine 캐시를 활용'으로 표현했습니다. 원본 측정 범위는 위에 근거로 남겨 두었으며 운영 규모의 성과로 확대하지 않았습니다. 복잡한 금융 약어와 계산 알고리즘 대신 규정 변경에 대응하기 쉬운 구조를 설명했습니다.
