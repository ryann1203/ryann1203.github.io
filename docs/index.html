DoLog — 대학 졸업전시 아카이빙 플랫폼 운영 중

2025.09 — 현재

전시가 끝난 뒤 흩어지는 작품과 작가 정보를 온라인에 기록하는 서비스입니다. 백엔드 개발과 서버 배포·운영을 담당해 3개 학과의 전시 아카이브를 운영했으며, 타 대학의 첫 유료 도입으로 이어졌습니다.

  • 작품·작가·전시·구역의 관계를 설계하고, 작품 등록·수정·삭제와 작품명·작가명 검색, 구역별 조회 API를 개발했습니다.
  • 작품 목록에서 전시 구역·공동 작가·작가 프로필을 읽을 때 발생한 N+1 쿼리를 분석하고, 연관 데이터를 함께 조회하도록 개선했습니다.
  • 기본 정보·공동 작가·상세 이미지가 함께 바뀌는 작품 수정을 하나의 트랜잭션으로 처리하고, 기능별 서비스를 분리해 변경 범위를 줄였습니다.
  • 가로 1,600px 초과 이미지 축소, WebP 변환, S3 저장을 공통 기능으로 구현했습니다. 운영 중 확인한 구역 미지정·이미지 없는 작품 등록 등의 예외도 보완했습니다.
  • 누적 조회 6,500+회 · 활성 사용자 약 900명. 실제 전시 데이터 취합부터 배포·운영까지 서비스 전체 흐름을 경험했습니다.

FedHybrid — 데이터 불균형에 대응하는 연합학습

2025.03 — 2025.12

기관별 원본 데이터를 공유하지 않고 모델 업데이트를 모아 공동 학습하는 프레임워크입니다. 서버·클라이언트 파이프라인을 구현하고, 데이터 분포가 다른 환경에서 정확도와 통신 비용을 비교했습니다.

  • 글로벌 모델 배포 → 로컬 학습 → 업데이트 수집·집계 → 다음 라운드로 이어지는 흐름과 참여 기관 수·대기 시간에 따른 집계 조건을 구현했습니다.
  • 중요한 업데이트만 선별하고 8-bit 양자화·가지치기를 적용해 통신 비용을 약 70~85% 절감했습니다(프로젝트 실험 기준).
  • CKKS 방식의 업데이트 암호화 전송과 서버 복호화·집계를 연결하고, FedAvg·FedProx 등 선행 기법과 동일 조건에서 성능을 비교했습니다.
  • 데이터 업로드·학습 로그·정확도 차트와 환자별 예측 결과 다운로드를 제공하는 웹 대시보드를 구현했습니다.

Voisk — NFC 기반 접근성 주문 시스템

2024.09 — 2024.12

시각장애인이 NFC 태그로 접속해 스마트폰의 VoiceOver·TalkBack으로 주문하는 서비스입니다. 프론트엔드를 담당해 접근성 주문 화면과 주문 상태, 서버 API 연동을 구현했습니다.

  • 한 화면에서 하나의 선택을 수행하는 순차적 구조로 메뉴·옵션·수량·장바구니·주문번호까지 이어지는 주문 흐름을 구현했습니다.
  • localStorage로 페이지 간 선택 상태와 장바구니를 유지하고, Fetch API로 주문을 전송해 응답의 주문번호를 표시했습니다.
  • VoiceOver로 아이스 아메리카노를 주문하는 비교 실험에서 동작 수를 메가커피 앱 129회 → Voisk 35회로 줄였습니다. 프로젝트 결과물로 특허를 출원했습니다.
